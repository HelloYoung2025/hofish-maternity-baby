Auf der offiziellen HOFISH-Seite können Sie versandte Pakete über die Sendungsnummer des Versanddienstes verfolgen. Die Seite bindet 17TRACK ein.

[Originalseite ansehen](<https://www.hofish.com/pages/order-tracking>) · Stand der Erfassung 2026-11-20

## Eine Sendung nachschlagen

- Die Sendungsnummer steht in der Versandmitteilung von HOFISH. Das Suchfeld erwartet die Nummer des Versanddienstes und unterscheidet sich von der Bestellreferenz des Shops.
- Öffnen Sie die Originalseite zur Sendungsverfolgung, geben Sie die Nummer ein und starten Sie die Suche. Das 17TRACK-Widget zeigt die verfügbaren Versandmeldungen.

## Wenn noch kein Status verfügbar ist

- Vergleichen Sie die Ziffern und Buchstaben mit der Versandmitteilung. Laut der alternativen Versandrichtlinie kann eine neue Sendung erst nach ein bis drei Arbeitstagen in der Verfolgung erscheinen.
- Bei mehreren Paketen zu einer Bestellung prüfen Sie die Nummer in der jeweiligen Versandmitteilung.
- Schreiben Sie an contact@hofish.net, falls Sie keine Sendungsnummer finden oder Hilfe zum Lieferstatus benötigen. Geben Sie Ihre Bestellreferenz an.
