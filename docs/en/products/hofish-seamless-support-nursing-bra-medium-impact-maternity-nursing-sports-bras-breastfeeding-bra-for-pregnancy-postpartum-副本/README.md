## Pumping and nursing access

- Open the front zipper to position the pump flange and use the opening to help hold it. HOFISH also illustrates the bra with wearable pumps. It does not specify compatible models.
- Undo a separate nursing clip to lower a cup for breastfeeding. The source pairs this design with a nursing top or a loose top for easier access.

## Fabric and care

- The smooth, full-coverage body is 91.4% nylon and 8.6% spandex. The listing describes the seamless fabric as lightweight, stretchy and breathable.
- Hand wash, or machine wash in a mesh bag as HOFISH recommends to help protect the zippers.

## Fit and options

- Sizes run from Medium to XX-Large. The color selector includes black, beige, black and beige, and light brown.
- The brand suggests considering the next size up if you prefer a looser fit or find the band too snug. The product page refers to its size guide. Use the sizing information for this zip-opening model.
