## For direct breastfeeding

- The collection includes full-coverage, deep-V and triple-clip nursing bras, a racerback sports bra and a longer camisole. All use cups or openings that can be released for breastfeeding.

## When pumping is also needed

- Four combined bras in this collection use layered fabric, cross-shaped openings or zipper access for pump flanges. Check which opening the item uses, plus strap adjustments, removable pads and any accessories listed for your selected variant.
