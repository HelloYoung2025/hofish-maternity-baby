Contact the HOFISH store about a product, order, delivery or return through its official customer service channels.

[View source page](<https://www.hofish.com/pages/contact>) · Source snapshot 2026-11-20

## Email and telephone

- Email contact@hofish.net or call +86 18059889045. HOFISH lists weekday availability, Monday through Friday, and gives no hours on the contact page.
- For a product question, give the item name and the size or color you are asking about. For an order question, include the order reference and a short description of the issue.

## Send a message using the store form

- Open the original HOFISH contact page, enter your name, email address and message, then submit the form there.
- Use an email address where HOFISH can reply. The contact page does not publish a response-time estimate.

## Find the right service page

- Use Order tracking for a parcel that has shipped. For return instructions or an incorrect item, see the refund page and confirm the applicable terms with HOFISH.
- For the recalled HF19HY mattress, use the dedicated recall page and the telephone number or email address in the CPSC notice.
