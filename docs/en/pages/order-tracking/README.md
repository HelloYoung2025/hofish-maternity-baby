The official HOFISH tracking page looks up shipped parcels using the carrier's tracking number. HOFISH embeds 17TRACK on that page.

[View source page](<https://www.hofish.com/pages/order-tracking>) · Source snapshot 2026-11-20

## Look up a parcel

- Find the tracking number in the shipping notice from HOFISH. The search field is for the carrier's number printed on the shipment, which differs from the store order reference.
- Open the original Order tracking page, enter the number, and submit it there. The 17TRACK widget displays any shipment events it has received.

## When tracking is unavailable

- Check the digits and letters against the shipping notice. The alternate Shipping policy says a new tracking record may take one to three working days to appear.
- If a single order was sent in separate parcels, check the tracking number shown for each parcel in its dispatch notice.
- Email contact@hofish.net if you cannot find the tracking number or need help interpreting the delivery status. Include your order reference so the store can locate the order.
