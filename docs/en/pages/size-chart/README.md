## How to use the product page

- Check the size choices and any fit information in the description or product images for the exact style. Some selectors spell out sizes such as X-Large, and others use XL or 2XL.
- The letters on the size selector alone do not tell you the matching band, cup, waist or hip measurements. Confirm the measurements with HOFISH if the item does not supply them.

## Deep-V seamless nursing bra, three-pack

- Small corresponds to U.S. sizes 32B–32DD and 34B–34C according to this product's description.
- Medium corresponds to 34D–34DD, 36B–36D and 38B–38C.
- Large corresponds to 38D–38DD and 40B–40D.
- X-Large corresponds to 42B, 42C, 42D and 42DD.
- The selector includes XX-Large. The description gives no matching band and cup measurements for this size. The ranges above belong to this Deep-V style.

## Leggings, jeans and shorts

- Check the product's size choices and whether it has a stretchy waistband or an over-bump panel. These details vary by style.
- Ask HOFISH about measurements using the item's name and the size you are comparing when the product page has no written chart.
