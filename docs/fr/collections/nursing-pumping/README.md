## Un soutien-gorge pour deux usages

- Sur le seul modèle affiché, un clip permet de rabattre le bonnet pour allaiter. Deux pans superposés à l’intérieur maintiennent les éléments du tire-lait pour un usage mains libres, sans zip à l’avant.

## Ajustement et variantes

- La fiche décrit des bretelles réglables, un dos à quatre positions et une rallonge. Le modèle est présenté de M à XL, seul ou en lot de deux. D’autres systèmes de tirage figurent dans le catalogue général des soutiens-gorge.
