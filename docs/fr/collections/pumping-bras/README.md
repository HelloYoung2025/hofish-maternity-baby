## Description de la collection

- Le descriptif met en avant des soutiens-gorge sans armatures pour allaiter et tirer son lait les mains libres au quotidien. Le relevé de la collection n’affiche aucune fiche.

## Vérifier l’ajustement sur la fiche produit

- La collection distincte Allaitement et tirage présente un modèle à pans de tissu superposés. Le catalogue général contient aussi des modèles zippés. Consultez la fiche précise pour les ouvertures, le tour de dessous de poitrine et l’ajustement des téterelles.
