Sur la page de suivi officielle de HOFISH, recherchez un colis expédié avec le numéro du transporteur. La page utilise le service 17TRACK.

[Consulter la page d’origine](<https://www.hofish.com/pages/order-tracking>) · Date du relevé 2026-11-20

## Consulter le suivi d’un colis

- Repérez le numéro de suivi dans la notification d’expédition de HOFISH. Le champ de recherche attend le numéro attribué par le transporteur, distinct de la référence de commande de la boutique.
- Ouvrez la page de suivi officielle, saisissez le numéro et lancez la recherche. Le module 17TRACK affiche les événements de livraison disponibles.

## Quand le suivi ne s’affiche pas

- Vérifiez les chiffres et les lettres dans la notification. La politique de livraison secondaire indique qu’il peut falloir un à trois jours ouvrés pour voir apparaître une nouvelle expédition.
- Si la commande a été répartie en plusieurs colis, vérifiez le numéro de chaque colis dans sa notification d’expédition.
- Si vous ne trouvez pas le numéro ou avez besoin d’aide pour comprendre le statut, écrivez à contact@hofish.net avec votre référence de commande.
